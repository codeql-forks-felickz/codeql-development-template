* Added `java/android/exported-provider-without-permissions`, which finds Android content providers that are explicitly exported without any `permission`, `readPermission`, `writePermission` or `<path-permission>` protection, or whose read or write access is guarded only by a permission declared in the same manifest with the default `normal` protection level (CWE-926). Providers with only one of `readPermission` or `writePermission` using a stronger permission remain reported by `java/android/incomplete-provider-permissions`.
* Added `java/improper-webview-certificate-validation-null-safe`, which finds `onReceivedSslError` handlers that call `SslErrorHandler.proceed()` behind a null check or non-null assertion of the handler, such as Kotlin `handler?.proceed()` or `handler!!.proceed()` (CWE-295). The standard `java/improper-webview-certificate-validation` query misses these because the call is conditional, or its qualifier is not a direct access to the handler parameter.
* Added `java/android/file-provider-root-path`, which finds FileProvider paths configurations whose `<root-path>` entry shares the device root directory (CWE-668).
* Added `java/android/unsafe-package-context-code-loading`, which finds calls to `Context.createPackageContext` with both `CONTEXT_INCLUDE_CODE` and `CONTEXT_IGNORE_SECURITY` (CWE-94, CWE-749).
* Added `java/tomcat-context-httponly-disabled`, which finds Tomcat `<Context>` elements that disable `HttpOnly` session cookies with `useHttpOnly` (CWE-1004).
* Added `java/android/unprotected-dynamic-broadcast-receiver`, which finds `Context.registerReceiver` and `ContextCompat.registerReceiver` calls that register a receiver for a custom action without a broadcast permission or `RECEIVER_NOT_EXPORTED` (CWE-925, CWE-926).
* Added `java/apache-httpclient-insecure-tls`, which finds Apache HttpClient 4.x and 5.x code that disables TLS validation with `NoopHostnameVerifier`, `AllowAllHostnameVerifier`, `TrustSelfSignedStrategy`, `TrustAllStrategy` or a `TrustStrategy` that always returns `true` (CWE-295, CWE-297).
